Smart Municipal Waste Collection & Route Optimization System

This is a software prototype developed as an academic demonstration of how Geographic Information Systems (GIS), waste-data analysis, vehicle management, and route optimization can help a municipality collect waste more efficiently — reducing unnecessary travel, fuel consumption, collection time, and operating cost.

All waste data, truck specifications, facility information, and collection records displayed in this application are simulated for academic demonstration. No real-time IoT sensors, GPS devices, or cloud services are used. The system runs entirely on localhost as a lightweight Flask web application.

Key Features

  • Source-Segregated Waste Tracking
    Every location reports waste by category: recyclable, organic, general, chemical, hazardous
  • Interactive GIS Map
    Leaflet + OpenStreetMap with markers, popups, heatmap, and collection zones
  • Fleet Management
    5 vehicles with capacity, fuel efficiency, and waste-type compatibility tracking
  • Route Optimization
    Nearest-neighbour heuristic with combined collection analysis to minimize travel
  • Normal vs Optimized Comparison
    Quantitative comparison of distance, fuel, time, and cost with percentage savings
  • Safety Compliance
    Chemical and hazardous waste enforced to specialized vehicles and facilities
  • Analytics & Forecasting
    Waste composition charts, daily trends, zone analysis, and simple predictive forecasting

Technology Stack

  • Python + Flask
    Backend server, routing logic, optimization algorithms
  • HTML5 + CSS3 + JavaScript
    Modern responsive dashboard UI with dark theme
  • Leaflet + OpenStreetMap
    Interactive GIS mapping with heatmap support
  • Chart.js
    Donut, bar, and line charts for analytics
  • JSON Data Storage
    Lightweight local data — no database required
  • Haversine + Nearest Neighbour
    Distance calculation and TSP heuristic for route optimization

Demonstration Flow

1. Login 2. Dashboard 3. GIS Map 4. Waste Sources 5. Generate Plan 6. Optimize Routes 7. Compare Results 8. Analytics
